Roam · Linux desktop

Automatic Wi-Fi roaming for Linux

Roam is a local Linux Wi-Fi roaming assistant that automatically switches between selected saved NetworkManager Wi-Fi networks when the current connection becomes weak or unstable.

Choose the saved profiles Roam may use. It works between different SSIDs and among independent access points, with no mesh network or cloud service required.

Roam is currently available to build from source. No GitHub releases or downloadable packages have been published yet; Debian, Fedora, and Arch packaging files in the repository are drafts.

NetworkManager Wi-Fi roaming

NetworkManager continues to control the connection. Roam adds a user-selected policy for switching when the current connection deteriorates. It is designed to work locally and does not send usage or network data to a service.
